## Overview

This repository documents the architectural design of
a distributed system for monitoring stock prices in
real time and notifying users when predefined price
thresholds are reached.

The proposed architecture incorporates:

- Event-driven microservices
- Real-time market data ingestion
- Distributed stream processing
- Cached threshold evaluation
- Asynchronous notification delivery
- Horizontal scalability and fault tolerance
- Cloud-native infrastructure on AWS

This project was originally completed as part of the
Software Design & Architecture course at South East
European University in May 2025.
